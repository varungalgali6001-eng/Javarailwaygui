# Railway Ticket Booking System

A Java Swing GUI application for railway ticket booking.

## Features

- Passenger details
- Train selection
- Travel class selection
- Seat availability checking
- Fare calculation
- Child and senior citizen discount
- Booking confirmation
- Ticket generation

## Technologies Used

- Java
- Java Swing
- AWT

## Main File

`RailwayBookingGUI.java`

## Run

```bash
javac RailwayBookingGUI.java
java RailwayBookingGUI
